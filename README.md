# java-lotto-precourse
## 기능 구현 목록

---

* 구입
  * 구입 금액 입력받기 (안내문구 별도 처리)
  * 1000 단위 아닐때 예외처리하는 기능
  * 로또 장수 계산하는 기능
  * 입력받은 문자열 숫자인지 체크하고 정수로 변환 하는 기능
  * 안내문구 출력 기능

* 로또 출력
  * 1~45 난수발생기능
  * 숫자 6개 오름차순으로 정렬하는 기능
  * 저장한 숫자 출력하는 기능
  * 장수만큼 로또 출력해서 전체 반환하는 기능


* 당첨 번호
  * 당첨번호 입력받는 기능
  * 안내문구 출력 기능
  * 당첨번호 입력받은거 쉼표 기준으로 파싱후 저장하는 기능
  * 보너스번호 입력받는 기능
  

* 당첨 확인
  * 숫자 당첨 번호랑 비교해서 몇개 같은지 확인하는 기능
  * 두개 합쳐서 당첨금액 확인하는 기능
  * 로또 발행 장수만큼 비교해주는 기능
  * 당첨금액에 따른 수익률 계산하는 기능

* 출력
  * 당첨통계 출력 기능
  * 수익률 출력 기능
