# java-lotto-precourse
## 기능 구현 목록

---

* 구입
  * 구입 금액 입력받기 (안내문구 별도 처리)
  * 1000 단위 아닐때 예외처리하는 기능
  * 입력 받은 금액 / 1000 으로 로또 장수 계산하는 기능


* 로또 출력
  * 1~45 난수발생기능
  * 난수발생기 실행시킨 숫자 저장하는 기능
  * 숫자 6개 오름차순으로 정렬하는 기능
  * 저장한 숫자 출력하는 기능


* 당첨 번호
  * 당첨번호 입력받는 기능
  * 1~45 아닐때 예외처리하는 기능
  * 당첨번호 입력받은거 쉼표 기준으로 파싱후 저장하는 기능
  * 보너스번호 입력받는 기능
  * 1~45 아닐때 예외처리
  

* 당첨 확인
  * 보너스볼이랑 같은 숫자 있는지 비교하는 기능
  * 숫자 당첨 번호랑 비교해서 몇개 같은지 확인하는 기능
  * 두개 합쳐서 당첨금액 확인하는 기능
  * 당첨금액에 따른 수익률 계산하는 기능


* 출력
  * 당첨통계 출력 기능
  * 수익률 출력 기능
